# Dropwave v0.3.1 — русский и английский / Russian & English

## 🇷🇺 Русский

**В интерфейс расширения добавлен английский язык.** В шапке меню появился компактный переключатель **RU / EN**, выбор сохраняется. При первом запуске язык определяется по языку браузера.

Переведены меню, история раздач, журнал получения, статусы, основные ошибки и уведомления. Описание расширения в браузере также локализовано. Минималистичный дизайн и механизм получения игр сохранены без изменений.

**Установка:** скачайте ZIP из Assets, распакуйте его, откройте `brave://extensions/` или `chrome://extensions/`, включите режим разработчика и выберите **Load unpacked / Загрузить распакованное расширение**. При обновлении существующего расширения замените файлы в прежней папке и нажмите Reload / Обновить, не удаляя расширение.

## 🇬🇧 English

**Dropwave now has an English interface!** A compact **RU / EN** selector appears in the popup header, and your language preference is saved. On first launch, the popup automatically uses your browser's UI language.

The popup, giveaway history, claim journal, statuses, common errors and desktop notifications are translated. The extension description is also localized. The minimal design and Steam claiming engine are unchanged.

**Install:** download the ZIP from Assets, extract it, open `brave://extensions/` or `chrome://extensions/`, turn on Developer mode, and select **Load unpacked**. When updating an existing installation, replace files in the original extension directory and click Reload without removing the extension.

**Note:** Steam may require signing in, age confirmation, or a region-eligible promotion. Browser must be running for background checks. Unofficial project, not affiliated with Valve or Steam.
